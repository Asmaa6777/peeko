What it is

A little creature that notices when you got something done.

It peeks

Peeko lives in the strip at the top of your screen. It looks at a few simple signals: which app is in front, whether you've touched the keyboard lately, and your public GitHub activity.

It ticks things off

When a signal says you did the thing, the task goes green on its own. It's not a to-do list: everything in the catalog is something your Mac can check.

It cheers, it doesn't police

These signals are hints, not proof. Leave a PDF open and nudge the mouse, and it'll count as reading. That's fine. Peeko is a nudge, not a lie detector.

Three faces

You can tell how your day is going from the eyes.

Every task wears one of Peeko's faces, and the menu bar icon shows the face for the whole day.

Examples

Things Peeko can tick off for you.

Read for 30 minutes

Counts active time while Preview is in front. Idle time doesn't count, and a sleeping Mac never adds hours.

time in an app

Deep work for 90 minutes

Same idea, across VS Code and Terminal. Point it at any app you like, for as many minutes as you want.

time in an app

Push to GitHub

Checks your public activity every 10 minutes for a push made today, in your own time zone.

online check

Slept on time

No screen time between 00:30 and 05:00? Peeko figures you got some sleep. If you were up late, it just says "no worries".

activity window

Up before 8

Your first stretch at the Mac after 4 AM starts before 8. All-nighters don't count as early mornings.

activity window

Write 300 words

Point Peeko at your notes folder or Obsidian vault. It counts the words you add today, or just ticks when a note changes.

notes folder

Committed code today

Point Peeko at your code folder. A commit by you in any repo there counts, private repos included, and nothing leaves your Mac.

on your Mac

Under 45 min of YouTube

Some goals are about doing less. The ring shows time used and turns pink near the limit. Stay under, and it counts as done.

stay under

Take a walk

After an hour at the screen, Peeko suggests standing up for 5 minutes. Stepping away resets the count.

break reminder

Tasks are just data

Every task is a type plus a few settings. Built-in presets live in a JSON file, and yours are saved the same way, so adding a new preset doesn't need any code.

{
  "id": "read-pdfs",
  "title": "Read for 30 minutes",
  "type": "appTime",
  "params": {
    "bundleIDs": ["com.apple.Preview"],
    "minutes": 30,
    "idleCutoffSeconds": 120
  }
}

Privacy

Everything stays on your Mac.

No account

Nothing to sign up for. No server, no analytics, no telemetry.

Plain files

Your tasks and history are JSON in ~/Library/Application Support/Peeko/. Read them, back them up, or delete them.

One network call

Only if you turn on the GitHub task: your public activity, every 10 minutes. Your notes folder and activity times never leave your Mac.

Install

Paste one line into Terminal.

curl -fsSL https://peeko.stack42.tech/install.sh | bash

It downloads the latest release, checks its checksum, puts Peeko in Applications, and opens it. Run it again to update. Read the script first if you like; it's short.

Prefer the DMG?

Download it from Releases and drag Peeko into Applications. It isn't signed with an Apple Developer ID yet, so the first time:

  1. Open Peeko once and close the warning.
  2. Go to System Settings → Privacy & Security.
  3. Click Open Anyway next to Peeko.

Build it yourself

All you need is Apple's Command Line Tools. No Xcode.

xcode-select --install
git clone https://github.com/STACK-42/peeko.git
cd peeko
make install

Needs macOS 14 Sonoma or later on an Apple silicon Mac.
